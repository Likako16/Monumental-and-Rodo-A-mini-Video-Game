# Monumental-and-Rodo-A-mini-Video-Game
This is a small exploration game featuring a player accompanied with their little robot helper. Together they explore an ancient cemetery and discover ancient artifacts. This game was programmed in godot for a diploma project.

This game is a prototype developed for experimental and academic purposes, so it may contain some bugs. In the future, i intend to release a full-fledged game of this version.
